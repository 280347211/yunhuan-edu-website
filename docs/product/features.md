# 云幻教育科技股份有限公司 - 企业官网

## 项目概述
为云幻教育科技股份有限公司打造简约大气的企业官网，展现教育科技行业专业形象。

## 页面结构

### 1. 首页 (Home)
- 全屏轮播横幅：展示公司核心品牌形象与主打产品
- 产品与方案：核心教育产品卡片展示，悬浮交互效果
- 关于我们：公司简介与核心数据，左文右图布局
- 成功案例：区域化案例卡片网格
- 新闻动态：最新企业新闻列表

### 2. 关于我们 (About)
- 公司简介：企业发展历程与愿景使命
- 文化荣誉：企业文化价值观与荣誉资质
- 发展历程：时间轴展示公司重要里程碑

### 3. 产品服务 (Products)
- 产品体系：3D/AR/VR 教育产品矩阵
- 解决方案：针对不同教学场景的方案展示
- 产品特色：技术优势与差异化亮点

### 4. 联系我们 (Contact)
- 联系方式：电话、邮箱、地址、微信
- 在线留言：表单提交
- 公司地图：办公地点展示

## 设计风格
- 蓝白主色调，科技教育感
- 中英双语区块标题
- 大面积留白，卡片式布局
- 简约大气的视觉语言
